*TEKNOFEST 2026 · International Efficiency Challenge Electric Vehicle Races · Hydromobile · **Finalist***

HİDROİST is İstanbul University–Cerrahpaşa's hydrogen-powered vehicle team. For the Efficiency Challenge, the team designed and built an energy-efficient hydrogen vehicle and raced it on track; as Software Team Lead, I led the development of the vehicle's driver-assistance (ADAS) software.

*TEKNOFEST 2026 · Unmanned Underwater Systems Competition · Advanced · **Finalist***

An underwater vehicle built to complete scenario-based missions both autonomously and under remote (ROV) control. The software stack covers underwater perception, autonomous navigation and embedded control.

**Highlights**
- YOLO-based target and object detection for underwater missions
- Autonomous navigation plus remote ROV operation
- PID control and IMU-based sensor fusion for stable depth and heading
- Flight-control integration with Pixhawk / ArduSub over MAVLink
- Embedded C++ and overall system design

**Technologies:** C++ · Python · YOLO · OpenCV · Transfer Learning · PID Control · Sensor Fusion · Pixhawk · ArduSub · MAVLink
